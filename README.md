# Aadame Pure — Luxury Botanical Skincare Shopify Theme

Custom high-conversion Shopify OS 2.0 theme engineered for **Aadame Pure**, inspired by modern luxury beauty brands and D2C leaders like SUGAR Cosmetics.

---

## 🌟 Key Features

### 1. Dynamic Homepage Experience
- **Cinematic Video Hero Banner**: Full-width video loop with interactive floating dewy micro-bubbles and one-click sound controls.
- **SUGAR-Style Circular Story Reels**: 6 luxury category reels with 360° rotating gold conic-gradient rings and responsive mobile-only arrow navigation.
- **Full-Width Cinematic Video Popup Modal**: Interactive full-width ritual film launched via the *"Watch Rituals ▶"* button with complete controls and direct add-to-bag actions.
- **Interactive Before / After Transformation Slider**: Draggable split-screen handle comparing Day 1 baseline with Day 14 glass-skin results, accompanied by Corneometer clinical metrics (+94% moisture, 88% redness calmed, 98% dewy glow).
- **Watch & Shop Video Reels**: Hover-to-play tutorial video cards with glass product pills and instant AJAX 1-click Quick Add to Bag.
- **Continuous 60fps Gold Ribbon Marquee**: Infinite ticker highlighting clean botanical and dermatological certifications.

### 2. High-Converting PDP (Product Detail Page)
- **Sticky Left Media Gallery**: Pinned at `top: 2rem` eliminating all empty scroll space.
- **Desktop Vertical Thumbnail Strip**: Left thumbnail strip with active indicator and smooth hover-to-zoom lens.
- **Available Offers Card**: One-tap copyable promo codes with auto-applied tier indicators.
- **Live Pincode & Delivery Estimator**: ZIP/Pincode verification with instant delivery timelines.
- **4-Pillar Trust Guarantee Strip**: 100% Clean & Vegan, Cruelty-Free, Dermat-Tested, 100% Authentic.
- **Luxury Gold-Embossed Gift Card**: Custom vector gift card graphic with responsive denominational pricing.

### 3. International Multi-Currency Localization
- Seamless country & currency selector with instant persistence and fallback support for 15 top global luxury markets.

---

## 🚀 Deployment & Shopify Setup

### Local Development
```bash
shopify theme dev --store glow-pure-store.myshopify.com
```

### Push to Remote Shopify Store
```bash
shopify theme push --path . --store glow-pure-store.myshopify.com
```
